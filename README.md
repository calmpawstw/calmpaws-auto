# 安寵 Calm Paws — 自動化內容管線

寵物舒緩音樂頻道的全自動產出、發佈與優化系統。

## 運作方式

| 排程 | 內容 |
|---|---|
| 週一 08:00 / 週三 20:00 / 週六 10:00（台灣時間） | 產出並上傳 YouTube 長片 |
| 每日 19:00 | 產出並發佈 Instagram Reel |
| 每日 07:00 | 收集 YouTube 與 Instagram 數據 |
| 週一 08:00 | 更新優化信念、產生營運週報 |
| 每 14 天 | Instagram Token 自動續期 |

## 優化引擎

在 7 個維度上跑 Thompson Sampling：主題情境、標題公式、縮圖風格、
影片長度、發布時段、Reel 開場、標籤組合。

報酬函數以觀看時數為主（60%），CTR 25%，留存率 15%。
這個配比對應 YouTube 合作夥伴計畫的門檻（1000 訂閱 + 4000 小時）。

三道守門：
- 探索地板 15%，避免鎖死在局部最佳
- 每維度至少保留 2 個活躍臂
- 新內容與近 5 支至少要有 2 個維度不同（差異化優先於報酬）

## 週報

每週一發佈於 GitHub Pages，並自動建立 Issue（會寄信通知）。
